# pdf-invoice

Form data exchange (FDF/XFDF) and ZUGFeRD/Factur-X e-invoicing for the PDFluent SDK.

This crate provides:

- **FDF/XFDF** import/export for AcroForm and XFA field data.
- **ZUGFeRD / Factur-X** PDF/A-3 embedded XML invoice attachments aligned with the
  EU eInvoicing standard (EN 16931, ZUGFeRD 2.x, Factur-X 1.x profiles).

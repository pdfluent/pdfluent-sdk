# pdf-xlsx

PDF table extraction and Excel (`.xlsx`) conversion for the PDFluent
commercial SDK.

This crate detects tabular regions in PDF pages and exports them as Office
Open XML SpreadsheetML workbooks suitable for downstream data processing.

# xfa-cli

PDFluent command-line interface: PDF and XFA processing — render, extract,
fill, flatten, validate, sign.

Provides the `pdfluent` binary plus a number of auxiliary tools used by the
test infrastructure (`xfa-collector`, `edge-case-report`).

## Status

Internal tool shipped with the PDFluent commercial SDK. See the workspace
`NOTICE` file for the per-crate license matrix.

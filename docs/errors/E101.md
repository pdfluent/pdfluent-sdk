# E101: File Not Found

**Error:** `PDFluentError::FileNotFound("document.pdf")`

**Uitleg:** Het opgegeven bestand kon niet worden gevonden op het bestandssysteem.

## Oorzaken

1. **Verkeerd pad**
   - Typfout in bestandspad
   - Relatief pad wordt opgelost vanuit verkeerde directory
   - Backslashes in plaats van forward slashes (Windows)

2. **Bestand bestaat niet**
   - Het bestand is verplaatst of verwijderd
   - Verkeerde bestandsextensie

## Oplossingen

### Rust
```rust
use std::path::Path;

let path = Path::new("documents/invoice.pdf");
if !path.exists() {
    eprintln!("File not found: {:?}", path);
    return;
}
let doc = sdk.open("documents/invoice.pdf")?;
```

### Python
```python
from pathlib import Path

path = Path("documents/invoice.pdf")
if not path.exists():
    raise FileNotFoundError(f"File not found: {path}")

doc = pypdfluent.open("documents/invoice.pdf")
```

### Node.js
```javascript
const fs = require('fs');
const path = 'documents/invoice.pdf';

if (!fs.existsSync(path)) {
    console.error(`File not found: ${path}`);
    return;
}

const doc = await pdfluent.open(path);
```

## Tips

- Gebruik absolute paden in productie
- Valideer bestandspaden voordat je `open()` roept
- Controleer `path.exists()` of gebruik `try_open()` voor error handling

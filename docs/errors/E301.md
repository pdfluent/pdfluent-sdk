# E301: XFA Not Found

**Error:** `PDFluentError::XfaNotFound`

**Uitleg:** Het PDF-document bevat geen XFA (XML Forms Architecture) content. Dit is normaal voor standaard PDF's.

## Oorzaken

1. **Regular PDF**
   - Het document is een standaard PDF zonder XFA forms
   - Het document gebruikt AcroForms in plaats van XFA

2. **Scanned document**
   - Gescand document (image-based) heeft geen XFA
   - OCR'd documenten hebben ook geen XFA

## Oplossingen

### Check if XFA is Present

```rust
use pdfluent::Sdk;

let sdk = Sdk::init_with_license("license.json")?;
let doc = sdk.open("document.pdf")?;

if doc.has_xfa() {
    let flat = doc.flatten_xfa()?;
    flat.save("flattened.pdf")?;
} else {
    println!("No XFA forms in this document");
    println!("This is a regular PDF or uses AcroForms");
}
```

### Handle Gracefully

```rust
use pdfluent::{Sdk, XfaError};

let sdk = Sdk::init_with_license("license.json")?;
let doc = sdk.open("document.pdf")?;

match doc.flatten_xfa() {
    Ok(flat) => flat.save("output.pdf")?,
    Err(XfaError::NotFound) => {
        println!("Document has no XFA forms");
        // Fall through or save original
    }
    Err(e) => return Err(e.into()),
}
```

### For AcroForms

If you need to work with AcroForms instead:

```rust
let doc = sdk.open("acroform.pdf")?;

for field in doc.acroform_fields() {
    println!("Field: {} = {}", field.name, field.value);
}
```

## When to Use XFA Operations

| Document Type | XFA Operations |
|---------------|----------------|
| XFA Dynamic Form | `flatten_xfa()`, `import_xfa_data()` |
| XFA Static Form | `flatten_xfa()` |
| AcroForm | `set_field_value()`, `get_field_value()` |
| Regular PDF | No form operations needed |
| Scanned PDF | Use OCR instead |

# E501: PDF/A Validation Failed

**Error:** `PDFluentError::PdfaValidationFailed("3 violations found")`

**Uitleg:** Het document voldoet niet aan de PDF/A standaard. Zie het validatie rapport voor details.

## Oorzaken

1. **Color space issues**
   - RGB in plaats van CMYK voor print
   - Device-specific color spaces used
   - ICC profile missing or incorrect

2. **Font embedding**
   - Fonts not embedded
   - Subset fonts with missing characters
   - Standard fonts used incorrectly

3. **Transparency**
   - Transparency groups used
   - Overprint settings
   - Blend modes not allowed in PDF/A

4. **Encryption**
   - Password-protected document
   - Metadata encryption

5. **JavaScript / Actions**
   - Interactive form actions
   - Document-level JavaScript
   - External links with actions

## Oplossingen

### Get Validation Report

```rust
use pdfluent::{Sdk, PdfaLevel};

let sdk = Sdk::init_with_license("license.json")?;
let doc = sdk.open("document.pdf")?;

let report = doc.validate_pdfa(PdfaLevel::A2b)?;

println!("PDF/A-2b Validation Report");
println!("===========================");
println!("Compliant: {}", report.is_compliant());
println!("Violations: {}", report.violation_count());

for violation in report.violations() {
    println!();
    println!("[{}] {}", violation.clause, violation.message);
    if let Some(loc) = violation.location {
        println!("  Location: page {}", loc.page);
    }
}
```

### Convert to PDF/A

```rust
let sdk = Sdk::init_with_license("license.json")?;
let doc = sdk.open("legacy.pdf")?;

// Try automatic conversion
match doc.convert_to_pdfa(PdfaLevel::A2b) {
    Ok(converted) => {
        let report = converted.validate_pdfa(PdfaLevel::A2b)?;
        if report.is_compliant() {
            converted.save("document_pdfa2b.pdf")?;
            println!("Successfully converted to PDF/A-2b");
        } else {
            eprintln!("Conversion succeeded but validation failed");
            for v in report.violations() {
                eprintln!("  {:?}", v);
            }
        }
    }
    Err(e) => eprintln!("Conversion failed: {}", e),
}
```

### Common Fixes

| Violation | Fix |
|-----------|-----|
| Font not embedded | Re-save with font embedding enabled |
| RGB color space | Convert to CMYK or use PDF/A-3 (allows RGB) |
| Transparency | Remove transparency or flatten |
| JavaScript present | Remove JS actions before conversion |
| Encryption | Remove password before validation |

### Validate Without Throwing

```rust
let doc = sdk.open("document.pdf")?;

let report = doc.validate_pdfa(PdfaLevel::A2b);
// Returns Result so you can check without exception

if !report.is_compliant() {
    // Handle non-compliant document
    println!("Document needs conversion: {} violations",
             report.violation_count());
}
```

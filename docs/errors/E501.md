# E501: PDF/A Validation Failed

**Error:** `PDFluentError::PdfaValidationFailed("3 violations found")`

**Uitleg:** Het document voldoet niet aan de PDF/A standaard. Zie het validatie rapport voor details.

## Oorzaken

1. **Color space issues**
   - RGB in plaats van CMYK voor print
   - Device-specific color spaces used
   - ICC profile missing or incorrect

2. **Font embedding**
   - Fonts not embedded
   - Subset fonts with missing characters
   - Standard fonts used incorrectly

3. **Transparency**
   - Transparency groups used
   - Overprint settings
   - Blend modes not allowed in PDF/A

4. **Encryption**
   - Password-protected document
   - Metadata encryption

5. **JavaScript / Actions**
   - Interactive form actions
   - Document-level JavaScript
   - External links with actions

## Oplossingen

### Get Validation Report

```rust
use pdfluent::prelude::*;

let doc = PdfDocument::open("document.pdf")?;
let report = doc.validate_pdfa(PdfAProfile::A2b)?;

println!("PDF/A-2b Validation Report");
println!("===========================");
println!("Compliant:   {}", report.is_compliant());
println!("Violations:  {}", report.violations.len());

for v in &report.violations {
    println!();
    println!("[{:?}] {} — {}", v.severity, v.rule, v.message);
}
```

### Inspect Violations Programmatically

```rust
use pdfluent::prelude::*;

let doc = PdfDocument::open("legacy.pdf")?;
let report = doc.validate_pdfa(PdfAProfile::A2b)?;
let errors: Vec<_> = report
    .violations
    .iter()
    .filter(|v| matches!(v.severity, pdfluent::compliance::Severity::Error))
    .collect();
println!("{} error-severity violations", errors.len());
```

### Common Fixes

| Violation | Fix |
|-----------|-----|
| Font not embedded | Re-save with font embedding enabled |
| RGB color space | Convert to CMYK or use PDF/A-3 (allows RGB) |
| Transparency | Remove transparency or flatten |
| JavaScript present | Remove JS actions before conversion |
| Encryption | Remove password before validation |

### Validate Without Aborting on Non-Compliance

```rust
use pdfluent::prelude::*;

let doc = PdfDocument::open("document.pdf")?;
// `validate_pdfa` returns a `Result<PdfAValidationReport>`. The
// report itself reports compliance via `is_compliant()`; non-
// compliance is not an error.
let report = doc.validate_pdfa(PdfAProfile::A2b)?;

if !report.is_compliant() {
    println!(
        "Document needs conversion: {} violation(s)",
        report.violations.len()
    );
}
```

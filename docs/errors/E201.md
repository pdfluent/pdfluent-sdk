# E201: Invalid PDF Structure

**Error:** `PDFluentError::InvalidPdfStructure("Invalid xref table")`

**Uitleg:** Het bestand is geen geldig PDF-document of is corrupted.

## Oorzaken

1. **Corrupted file**
   - Bestand is niet volledig gedownload
   - Schijf- of netwerkfout tijdens opslaan
   - Bestand bewerkt met externe editor

2. **Wrong file type**
   - Een Word, Excel, of ander document wordt geopend als PDF
   - HTML of tekst bestand met `.pdf` extensie
   - Image (PNG/JPG) opgeslagen als PDF

3. **Version incompatibility**
   - PDF 2.0 features gebruikt door oudere library
   - Speciale compressie methode niet ondersteund

## Oplossingen

### Rust
```rust
use pdfluent::Sdk;

let sdk = Sdk::init_with_license("license.json")?;

match sdk.open("document.pdf") {
    Ok(doc) => { /* valid PDF */ }
    Err(e) if e.to_string().contains("InvalidPdfStructure") => {
        eprintln!("Not a valid PDF: {}", e);
    }
    Err(e) => return Err(e),
}
```

### Python
```python
try:
    doc = pypdfluent.open("document.pdf")
except pypdfluent.InvalidPdfStructure as e:
    print(f"Invalid PDF: {e}")
    # Check if it's actually a PDF
    with open("document.pdf", "rb") as f:
        header = f.read(8)
        if not header.startswith(b"%PDF-"):
            print("This is not a PDF file at all!")
```

### Node.js
```javascript
try {
    const doc = await pdfluent.open("document.pdf");
} catch (e) {
    if (e.code === 'E201') {
        console.error('Invalid PDF structure:', e.message);
    }
}
```

## Validate Before Opening

```rust
// Check PDF header before processing
fn is_valid_pdf(path: &str) -> bool {
    use std::io::Read;
    let mut file = std::fs::File::open(path).ok();
    let mut header = [0u8; 8];
    file.as_mut().unwrap().read_exact(&mut header).ok();
    &header[..5] == b"%PDF-"
}
```

# E401: Invalid Signature

**Error:** `PDFluentError::InvalidSignature("Certificate chain validation failed")`

**Uitleg:** De digitale handtekening kon niet worden gevalideerd.

## Oorzaken

1. **Certificate expired**
   - Het ondertekeningscertificaat is verlopen
   - De timestamp certificate is verlopen

2. **Trust chain broken**
   - Root CA niet in trusted store
   - Intermediate certificates missing

3. **Document modified**
   - PDF is gewijzigd na ondertekening
   - Handtekening is verwijderd of beschadigd

4. **Wrong certificate**
   - Privaat key komt niet overeen met certificaat
   - Verkeerd certificaat gebruikt

## Oplossingen

### Verify Before Trusting

```rust
use pdfluent::Sdk;

let sdk = Sdk::init_with_license("license.json")?;
let doc = sdk.open("signed_document.pdf")?;

let signatures = doc.verify_signatures();

for sig in signatures {
    if !sig.is_valid() {
        eprintln!("Invalid signature: {}", sig.error());
        eprintln!("  Signer: {}", sig.signer());
        eprintln!("  At: {}", sig.timestamp().unwrap_or_default());

        // Detailed validation
        let details = sig.validate_full()?;
        if !details.certificate_valid {
            eprintln!("  Certificate issue: {:?}", details.certificate_error);
        }
        if !details.integrity_valid {
            eprintln!("  Document may have been modified!");
        }
    }
}
```

### Check Certificate Expiry

```rust
let sig = signatures.first().unwrap();

// Check if certificate is currently valid
let now = std::time::SystemTime::now();
if let Some(not_before) = sig.cert_valid_from() {
    if now < not_before {
        eprintln!("Certificate not yet valid!");
    }
}
if let Some(not_after) = sig.cert_valid_until() {
    if now > not_after {
        eprintln!("Certificate has expired!");
    }
}
```

### Add Trusted Certificates

```rust
let mut trust_store = pdfluent::TrustStore::new();

// Add your organization's root CA
trust_store.add_ca("certs/company_root.pem")?;

let result = doc.verify_signatures_with_trust(&trust_store)?;
```

## Signature Verification Results

| Check | Description |
|-------|-------------|
| `is_valid()` | Overall signature validity |
| `certificate_valid` | Certificate chain validates |
| `integrity_valid` | Document not modified |
| `timestamp_valid` | RFC 3161 timestamp valid |
| `revocation_checked` | CRL/OCSP checked |

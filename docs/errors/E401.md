# E401: Invalid Signature

**Error:** `PDFluentError::InvalidSignature("Certificate chain validation failed")`

**Uitleg:** De digitale handtekening kon niet worden gevalideerd.

## Oorzaken

1. **Certificate expired**
   - Het ondertekeningscertificaat is verlopen
   - De timestamp certificate is verlopen

2. **Trust chain broken**
   - Root CA niet in trusted store
   - Intermediate certificates missing

3. **Document modified**
   - PDF is gewijzigd na ondertekening
   - Handtekening is verwijderd of beschadigd

4. **Wrong certificate**
   - Privaat key komt niet overeen met certificaat
   - Verkeerd certificaat gebruikt

## Oplossingen

### Verify Before Trusting

```rust
use pdfluent::prelude::*;

let doc = PdfDocument::open("signed_document.pdf")?;
let report = doc.verify_signatures()?;

if !report.is_signed() {
    eprintln!("Document has no signatures.");
}

for v in report.validations() {
    match &v.status {
        SignatureStatus::Valid => {
            println!("{}: valid", v.info.field_name);
        }
        SignatureStatus::Invalid { reason } => {
            eprintln!("{}: invalid — {}", v.info.field_name, reason);
        }
        SignatureStatus::Unknown { reason } => {
            eprintln!("{}: unknown — {}", v.info.field_name, reason);
        }
    }
}
```

### Inspect Signature Metadata

```rust
use pdfluent::prelude::*;

let doc = PdfDocument::open("signed_document.pdf")?;
for sig in doc.signatures()? {
    println!(
        "field={} signer={} timestamp={:?} profile={:?}",
        sig.field_name, sig.signer_name, sig.timestamp, sig.profile
    );
}
```

## Signature Verification Results

| Check | Where |
|-------|-------|
| `SignatureStatus::Valid` | cryptographically valid + trusted chain |
| `SignatureStatus::Invalid { reason }` | crypto / integrity failure |
| `SignatureStatus::Unknown { reason }` | chain unknown / cannot validate |
| `SignatureValidationReport::is_signed()` | distinguishes vacuously-valid unsigned doc |

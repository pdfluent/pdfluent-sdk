How to open a PDF in Rust

First make sure you have pdfluent in your Cargo.toml:

[dependencies]
pdfluent = "1"

And a quick shell check:

$ cargo build

Now the Rust code:

use pdfluent::prelude::*;

fn main() -> Result<()> {
    let doc = PdfDocument::open("sample.pdf")?;
    println!("{} pages", doc.page_count());
    Ok(())
}
